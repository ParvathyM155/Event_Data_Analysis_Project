📋 Project Overview

This project loads the raw Airbnb Open Data Excel file, applies a multi-step cleaning pipeline, computes summary statistics, and generates 8 charts that reveal pricing patterns, neighbourhood distributions, and correlations across the NYC listings dataset.

🧹 Data Cleaning Steps

Step Action Detail
1 Column normalisation Strip whitespace · lowercase · replace spaces with _
2 Typo fixes "brookln" → Brooklyn · "manhatan" → Manhattan
3 Drop unused column license column removed
4 Remove duplicates 541 exact duplicate rows dropped
5 Drop nulls Rows missing price, neighbourhood_group, or room_type removed
6 Filter invalid prices Kept only price > 0
7 Filter minimum_nights Kept values between 1 and 365
8 Filter availability_365 Kept values between 0 and 365
